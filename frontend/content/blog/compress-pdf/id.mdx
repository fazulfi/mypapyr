# Cara Mengompres PDF: Panduan Lengkap

File PDF besar lebih lambat diunggah, sulit dikirim melalui email, dan memerlukan ruang lebih banyak. Mengompres PDF mengurangi ukuran file sambil menjaga isi tetap mudah dibaca. Panduan ini menjelaskan prosesnya dan cara memakai [alat Kompres PDF](/id/kompres-pdf) gratis dari Papyr.

## Apa yang terjadi

PDF dapat berisi teks, font, gambar, dan bentuk vektor. Gambar biasanya menyumbang sebagian besar ukuran file. Kompresi menyandikan ulang gambar dengan pengaturan yang lebih efisien, misalnya resolusi lebih rendah saat detail tidak diperlukan, warna yang lebih hemat, dan metadata yang lebih bersih. Teks tetap tajam karena disimpan sebagai teks, bukan gambar.

## Kapan berguna

Kompresi membantu saat ada batas ukuran lampiran email atau unggahan situs. File juga dapat terbuka lebih cepat pada koneksi lambat. Hasilnya mungkin kecil untuk dokumen teks sederhana tanpa gambar. Kompresi tidak menghapus halaman, mengubah urutan, atau mengganti arti dokumen.

## Cara memakai Papyr

[Alat Kompres PDF](/id/kompres-pdf) menggunakan satu profil otomatis berkualitas tinggi.

1. Buka alat tersebut.
2. Pilih file PDF; batasnya 20 MB per file.
3. Tunggu Papyr memproses file.
4. Unduh hasilnya dan periksa kembali.

File diproses di server Papyr dan dihapus otomatis dalam waktu 1 jam. Tautan unduhan juga bersifat sementara. Anda tidak perlu membuat akun, dan file hanya digunakan untuk proses yang diminta.

## Tips pemeriksaan

Buka hasil kompresi sebelum membagikannya. Untuk dokumen hasil pemindaian, periksa apakah resolusi asli lebih tinggi dari kebutuhan. Kompresi tidak dapat menambahkan detail yang tidak ada. Jika file masih besar, periksa foto beresolusi tinggi atau font yang tertanam pada sumbernya.

**Tip:** simpan file asli sampai Anda yakin semua halaman penting tetap terbaca.

## Mulai

Gunakan [alat Kompres PDF](/id/kompres-pdf) untuk mengecilkan file tanpa memasang aplikasi tambahan.

## Sebelum membagikan

Baca seluruh hasil dan pastikan isinya sesuai kebutuhan. Simpan salinan sumber selama pemeriksaan, gunakan folder lokal dengan izin yang sesuai, dan hapus salinan sementara setelah tidak diperlukan. Pemeriksaan ini membantu menemukan halaman yang hilang, urutan yang salah, dan masalah keterbacaan sebelum file dikirim.

Simpan file asli sampai pemeriksaan akhir selesai. Periksa juga nama, ukuran, dan folder untuk menyimpan hasilnya.

Pemeriksaan akhir ini membantu menemukan versi lama, halaman yang terlewat, dan urutan yang salah sebelum dokumen dikirim.

Sebelum selesai, bandingkan hasil dengan tujuan Anda dan pastikan tidak ada halaman yang tidak diperlukan.

Periksa hasil sekali lagi sebelum menghapus salinan sementara atau membagikan tautan unduhan.

Sebelum menghapus file sementara, buka hasil pada ukuran penggunaan sebenarnya dan pastikan halaman penting tetap lengkap. Jika ada beberapa versi, gunakan nama file yang jelas agar hasil yang sudah diperiksa mudah dibedakan dari sumbernya. Untuk pekerjaan yang akan dikirim, simpan hasil di lokasi yang Anda kenali dan periksa kembali bahwa file dapat dibuka setelah dipindahkan.
