# Cara Menggabungkan PDF: Satukan Beberapa File Menjadi Satu

Menggabungkan PDF berguna ketika laporan, kuitansi, hasil pemindaian, atau bagian proyek tersimpan sebagai file terpisah. Satu dokumen lebih mudah dikirim, dicetak, dan ditinjau. Panduan ini menjelaskan persiapan dan penggunaan [alat Gabungkan PDF](/id/gabungkan-pdf).

## Persiapan

Tentukan file yang harus berada di awal dan halaman yang perlu dipertahankan. Buka setiap PDF untuk memeriksa arah halaman dan keterbacaan. Gunakan salinan jika file asli harus tetap utuh. Penggabungan hanya menyusun halaman; proses ini tidak memperbaiki kerusakan, kata sandi, atau izin akses.

## Cara memakai Papyr

[Alat Gabungkan PDF](/id/gabungkan-pdf) berjalan di browser, sehingga file Anda tidak pernah meninggalkan perangkat.

1. Buka alat tersebut.
2. Pilih semua PDF yang diperlukan.
3. Atur urutan file.
4. Hapus file ganda atau yang tidak diperlukan.
5. Jalankan proses lalu unduh hasilnya.

Hasil mengikuti urutan yang terlihat. File sumber tetap berada di perangkat Anda dan browser membuat dokumen gabungan secara lokal. Periksa setiap pemberitahuan unduhan sebelum menyetujuinya.

## Periksa hasil

Lihat halaman awal, akhir, dan perpindahan antarfile. Ukuran halaman, bookmark, serta metadata dapat berbeda karena berasal dari dokumen sumber. Jika tampilan harus seragam, samakan dokumen sumber terlebih dahulu.

## Kesalahan umum

Urutan yang salah adalah masalah paling sering. File dengan nama mirip juga dapat menyebabkan duplikasi. Buat daftar file yang diharapkan dan bandingkan dengan hasil. Jangan menghapus file asli sebelum semua halaman diperiksa.

**Tip:** simpan sumber sampai pemeriksaan selesai agar urutan dapat diperbaiki dengan mudah.

## Mulai menggabungkan

Gunakan [alat Gabungkan PDF](/id/gabungkan-pdf) untuk membuat satu dokumen teratur tanpa mengunggah file Anda.

## Sebelum membagikan

Baca seluruh hasil dan pastikan isinya sesuai kebutuhan. Simpan salinan sumber selama pemeriksaan, gunakan folder lokal dengan izin yang sesuai, dan hapus salinan sementara setelah tidak diperlukan. Pemeriksaan ini membantu menemukan halaman yang hilang, urutan yang salah, dan masalah keterbacaan sebelum file dikirim.

Simpan file asli sampai pemeriksaan akhir selesai. Periksa juga nama, ukuran, dan folder untuk menyimpan hasilnya.

Pemeriksaan akhir ini membantu menemukan versi lama, halaman yang terlewat, dan urutan yang salah sebelum dokumen dikirim.

Sebelum selesai, bandingkan hasil dengan tujuan Anda dan pastikan tidak ada halaman yang tidak diperlukan.

Periksa hasil sekali lagi sebelum menghapus salinan sementara atau membagikan tautan unduhan.

Simpan sumber sampai Anda memeriksa halaman pertama, halaman terakhir, dan beberapa bagian di tengah dokumen.

Dokumen yang sudah diperiksa sebaiknya disimpan di lokasi yang jelas agar versi yang benar mudah ditemukan.

Sebelum menghapus file sementara, buka hasil pada ukuran penggunaan sebenarnya dan pastikan halaman penting tetap lengkap. Jika ada beberapa versi, gunakan nama file yang jelas agar hasil yang sudah diperiksa mudah dibedakan dari sumbernya. Untuk pekerjaan yang akan dikirim, simpan hasil di lokasi yang Anda kenali dan periksa kembali bahwa file dapat dibuka setelah dipindahkan.
