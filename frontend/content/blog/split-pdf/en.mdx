# How to Split a PDF: Extract Pages You Need

Splitting a PDF helps when you need to share a small section, archive selected pages, or separate a long document into individual files. The important step is choosing page ranges carefully. This guide explains the process and how to use the free [Split PDF tool](/en/split-pdf).

## When splitting helps

A long PDF may contain several independent sections. Extracting only the relevant pages can make a review easier and reduce the size of an attachment. Splitting can also create one PDF per page when each page must be handled separately. It does not edit the text or redesign the page; it selects pages from the original document.

## Plan page ranges

Count pages using the PDF viewer's page indicator, not printed page numbers inside the document. Printed numbers may start at a different value or skip pages. Write down ranges such as 1-3 and 8-10 before starting. Avoid overlapping ranges unless you intentionally want the same page in more than one output.

## How to split a PDF with Papyr

Papyr's [Split PDF tool](/en/split-pdf) runs in your browser, so your files never leave your device.

1. Open the Split PDF tool.
2. Select a PDF from your device.
3. Enter custom page ranges or choose one output per page.
4. Review the requested ranges and start the operation.
5. Download the generated PDF files.

The tool follows the ranges you provide. If you choose one file per page, every selected page becomes its own PDF. Keep the source file while checking the outputs, because it is the simplest reference for confirming that no page was missed.

## Check extracted files

Open each result and confirm the first and last page. Pay attention to pages containing images, tables, forms, or rotated content. A split operation does not add a cover page or renumber the source. If you need a different presentation, make that change in a separate document editor after extraction.

## Common mistakes

Using printed page numbers instead of viewer indexes can select the wrong content. Empty ranges, reversed ranges, and accidental spaces can also cause validation errors. Another mistake is deleting the original before checking every output. Keep a temporary copy until the extracted pages are safely stored.

**Tip:** name outputs by their section or range after downloading, but do not include confidential document details in filenames when sharing a device or folder.

## Extract your pages

Prepare your page ranges, then use the free [Split PDF tool](/en/split-pdf) to extract the pages you need locally.
